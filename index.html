openwrt-addon-feed

Add this feed

These are the add-on packages: apman, snapcast-mptcp/homesync, the wpad variants, nsca-ng, usb-relay-hid and the lua bits. The modem stack (wwand and its LuCI apps) lives in openwrt-repo — both are signed with the same key, so a device that already trusts one trusts this one too.

Install ddimension-feed from the other feed once; it writes a .list for both. By hand, for one device:

cat >/etc/apk/repositories.d/ddimension-addon.list <<EOF
https://ddimension.github.io/openwrt-addon-feed/stable/<release>/<arch>/packages.adb
EOF
apk update

stable = releases, main = development.
